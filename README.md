# Santasa Wellness – Emotional Wellness & Relationship Coaching

A responsive, elegant, and user-friendly website for **Santasa Emotional Wellness and Coaching**, founded by Keerthi B. Nadig. The website provides information about relationship coaching services, the coaching approach, professional qualifications, and ways to connect with the coach.

🌐 **Website:** [https://www.santasawellness.com](https://www.santasawellness.com)

---

## 📌 About the Project

Santasa Wellness is a website designed to establish an online presence for an emotional wellness and relationship coaching practice based in Bengaluru, India.

The website aims to help individuals and couples explore relationship coaching services, understand the coaching process, learn about the founder, and get in touch for appointments.

The design focuses on creating a calm, welcoming, accessible, and professional digital experience.

## ✨ Key Features

- **Responsive Design:** Optimised for desktop, tablet, and mobile devices.
- **Modern Landing Page:** Clean hero section with clear messaging and consultation calls to action.
- **About Section:** Introduction to Santasa Wellness and its philosophy.
- **Relationship Coaching Services:** Dedicated sections for:
  - Marriage and Relationship Coaching
  - Premarital Relationship Coaching
  - Individual Relationship Coaching
  - Emotional Awareness and Communication
- **Relationship Challenges:** Highlights common relationship concerns.
- **Coaching Approach:** Explains the five-step coaching process.
- **Benefits Section:** Outlines the potential benefits of relationship coaching.
- **Meet Your Coach:** Professional introduction, qualifications, and recognitions of Keerthi B. Nadig.
- **Testimonials:** Interactive testimonial carousel showcasing client experiences.
- **FAQs:** Expandable accordion for frequently asked questions.
- **Consultation Section:** Encourages visitors to enquire about coaching sessions.
- **Contact Information:** Provides direct contact options.
- **WhatsApp Integration:** Floating WhatsApp button for quick enquiries.
- **Legal Information:** Privacy Policy, Coaching Disclaimer, and Terms and Conditions displayed through interactive modals.
- **Smooth Animations:** Scroll-reveal effects and interactive UI transitions.

## 🎨 Design Approach

The website follows a minimal, elegant, and wellness-focused design language.

**Colour Palette:**
- Sage Green – `#4A6B5D`
- Cream – `#FAF8F5`
- Terracotta – `#C87D65`
- Charcoal – `#2C3531`
- Sand – `#E6E0D6`

**Typography:**
- Playfair Display – Headings
- Plus Jakarta Sans – Body text

The visual design prioritises readability, whitespace, consistent typography, and a calming user experience.

## 🚀 Getting Started

You can run the website locally without installing any additional dependencies.

**1. Clone the repository**

```bash
git clone https://github.com/your-username/santasa-wellness.git
```

**2. Navigate to the project folder**

```bash
cd santasa-wellness
```

**3. Open the website**

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.
